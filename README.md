# Application de gestion des tâches

## 1. Présentation du projet

Ce projet consiste à développer une application simple de gestion des tâches en utilisant le langage Python.

L'application fonctionne en mode console et permet à l'utilisateur de gérer ses tâches à travers un menu interactif.

## 2. Objectifs du projet

- Apprendre les bases de la programmation Python.
- Manipuler les listes et les chaînes de caractères.
- Utiliser les conditions et les structures répétitives.
- Découvrir les commandes de base de Git.
- Organiser et documenter un projet informatique.

## 3. Fonctionnalités principales

L'application propose un menu principal avec les fonctionnalités suivantes :

### 1. Ajouter une tâche
Permet à l'utilisateur de saisir le titre d'une nouvelle tâche et de l'ajouter à la liste.

### 2. Afficher les tâches
Affiche toutes les tâches enregistrées avec leur numéro correspondant.

### 3. Rechercher une tâche
Permet de rechercher une tâche à partir d'un mot-clé saisi par l'utilisateur.

### 4. Quitter l'application
Permet de terminer l'exécution du programme avec un message de confirmation.

## 4. Technologies utilisées

- **Langage de programmation :** Python 3
- **Éditeur de code :** Visual Studio Code
- **Gestion de versions :** Git
- **Plateforme de partage :** GitHub

## 5. Structure du projet

Le projet contient les fichiers suivants :

- `main.py` : contient le code source de l'application.
- `README.md` : présente le projet et explique son fonctionnement.

## 6. Exécution du programme

Pour lancer l'application sans utiliser de commande :

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** en haut à droite.
4. Le menu principal s'affiche dans le terminal.
5. Choisir une option en saisissant le numéro correspondant.

## 7. Exemple d'utilisation

```text
===== MENU PRINCIPAL =====
1 - Ajouter une tâche
2 - Afficher les tâches
3 - Rechercher une tâche
0 - Quitter

Votre choix : 1
Donner le titre de la tâche : Réviser Python
```
